# AI 교육적 효과 인식 설문 App

이 앱은 Streamlit과 SQLite3를 기반으로 작성되었습니다.

## 실행 방법

1. 필요한 패키지 설치:
   ```bash
   pip install -r requirements.txt
   ```

2. 앱 실행:
   ```bash
   streamlit run app.py
   ```

## 게임 화면 개선 (2026-10-28)

- 블록리게임 / 테트리스게임 / pythonid 화면이 하나의 프레임 안에 잘리지 않고 표시되도록 수정
  (기존: 바깥 820px 안에 1800px iframe → 이중 스크롤·화면 잘림)
- 화면 높이 조절 슬라이더, "새 창에서 크게 열기" 버튼 추가
- 새 메뉴 "게임 함께보기": 블록리 + 테트리스를 좌우로 나란히 표시

## 학습 이력 · 햄버거 메뉴 추가 (2026-11-11)

- **learninghistory 테이블** `(id_num, userid, menu_id, std_time, end_time, waiting_time, created_at)`
  - 메뉴를 클릭하면 새 기록이 INSERT 되고(std_time), 다른 메뉴를 클릭하거나 로그아웃하면
    이전 기록의 end_time 과 체류 시간 waiting_time(**초 단위**)이 UPDATE 됩니다.
  - 비로그인 상태의 이용은 userid = `guest` 로 기록됩니다.
  - menu_id: M01 Home, M02 Login, M03 SignUp, M04 설문참여, M05 pythonid,
    M06 블록리게임, M07 테트리스게임, M08 게임 함께보기
- **햄버거 메뉴(☰)**: 왼쪽 위 버튼을 누르면 좌측 메뉴가 슬라이드로 열리고,
  메뉴 선택 · ✕ 버튼 · 어두운 배경 클릭 시 다시 슬라이드로 닫힙니다.
- **메뉴 재배치**: 로그아웃 후 다시 로그인하면 learninghistory 의 누적 체류시간
  (같으면 클릭 수) 순으로 학습 메뉴가 재배치됩니다. Home은 맨 위, 계정 메뉴는 맨 아래 고정.
- Home 화면에서 로그인 사용자의 메뉴별 누적 체류시간과 최근 기록을 확인할 수 있습니다.
- Streamlit 1.50 이상 필요 (`st.container(key=...)`, `width="stretch"` 사용)

## 상위/하위 메뉴(아코디언) · 우측 상단 계정 버튼 (2026-11-17)

| 상위 메뉴 | 하위 메뉴 (menu_id) |
|---|---|
| 🎮 게임 | 블록리 게임(M06), 테트리스 게임(M07) |
| 🐍 파이썬 학습 | pydroid(M05), 파이썬 강좌(M09) |
| 📋 설문참여 | 설문참여(M04) |
| 📺 유튜브 시청 | AI학습(M10), 주식강좌(M11) |

- 상위 메뉴를 누르면 하위 메뉴가 부드럽게 펼쳐지고, 오른쪽 ▼ 아이콘이 ▲로 회전합니다.
- 다른 상위 메뉴를 누르면 열려 있던 메뉴는 자동으로 닫힙니다. 같은 메뉴를 다시 누르면 접힙니다.
- 현재 페이지의 하위 메뉴는 배경색·글자색으로, 그 상위 메뉴는 글자색으로 강조됩니다.
- 상위 메뉴 클릭은 페이지 이동이 아니므로 learninghistory에 기록하지 않고, 하위 메뉴 클릭만 기록합니다.
- 로그인 시 하위 메뉴는 누적 체류시간 순, 상위 메뉴는 하위 메뉴 체류시간 합계 순으로 재배치되며
  가장 많이 이용한 상위 메뉴가 펼쳐진 상태로 메뉴가 열립니다.
- Login / SignUp 버튼은 오른쪽 위로 옮겼고, 로그인하면 그 자리에 사용자 ID와 로그아웃 버튼이 보입니다.
- AI학습 / 주식강좌 페이지: app.py의 `YOUTUBE_LIBRARY[...]["videos"]`에 영상 주소를 넣으면
  페이지에 바로 표시됩니다. 화면에서 주소를 붙여 넣어 시청할 수도 있습니다.
- 기존 '게임 함께보기'는 메뉴에서 숨겼습니다. `MENUS`에서 group을 "G_GAME"으로 바꾸면 다시 나타납니다.

## 상위 메뉴 총 체류시간 · 로그인 시 메뉴 재배치 (2026-11-17)

- 상위 메뉴 오른쪽에 하위 메뉴 체류시간을 합산한 **총 체류시간**이 표시됩니다. (예: 📺 유튜브 시청 · 총 5분 3초)
- Home 화면에 **상위 메뉴별 총 체류시간** 표와 차트를 추가했습니다.
- 메뉴 순서는 **로그인할 때 한 번** learninghistory로 계산해 `st.session_state['menu_order']`에 저장합니다.
  - 로그인 중에는 순서가 바뀌지 않고(시간 표시는 계속 갱신), 로그아웃하면 기본 순서로 돌아가며,
    다시 로그인하면 최신 이력으로 재배치됩니다.
  - 상위 메뉴: 하위 메뉴 체류시간 합계 순 / 하위 메뉴: 각자의 체류시간 순
